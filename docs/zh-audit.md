# 中文文案易误读检查

对 251 条逐条过，按「主语缺失 / 一词多指 / 动作词不统一 / 说法不准」四类挑出来的问题。
级别：**高**＝会被理解成另一件事；**中**＝能读懂但容易犹豫或多想一步；**低**＝语感。

| 级别 | 涉及键 | 现在 | 问题 | 建议 |
|---|---|---|---|---|
| 高 | `S_AUTOSTART`、`S_H9`、`S_AUTOSTART_NOTE`、`S_MSG_AUTO_ON/OFF/PATCHING/UNSUPPORTED/FAILED/LATER` | 开机自启 | 标签没有主语，会被读成「**这个软件**开机自启」；实际是**录制器**被 Luma 在开机时拉起，主程序不参与 | 随主机启动（对照表里乌语的 `Запуск з консоллю`） |
| 高 | `S_PILL_ON`、`S_PILL_OFF` | 已开启 / 已关闭 | 就贴在大字「录制中 00:12」右边，容易被读成「录制已开启」 | 录制器开 / 录制器关 |

## 已经统一、不用改的

- **启动 / 开启 / 打开**：录制器（进程）用「启动」，功能开关用「开启」，程序、页面、Wi-Fi 用「打开」。三个词各管一类，不是混用。
- **卸载 / 删除**：程序用「卸载」，文件与录像用「删除」。乌语原文两边都用 `видалити`，中文保留这个区分更准。
- **上屏 / 下屏 / 双屏**：与设置项的值、录像库信息行一致。
- **本程序 / 主机 / 面板**：分别指这个 App、3DS 本体、App 的首页面板，全篇一致。

## 说明

- 表中「建议」都按现有位置估过宽度：设置行、状态胶囊、统计卡片、快捷键提示行都放得下。
- 「随主机启动」若还想更明确，设置行可以写成「录制器随主机启动」（8 字，约 76 px，行宽 300 px）。
